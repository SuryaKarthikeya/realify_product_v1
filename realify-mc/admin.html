Rollout · deployed features & versions

Instant, no redeploy. Pick the version (build) to run and its scope — rollback = pick a previous version or scope off. Version = presentation (safe). Feature gates = whether a capability may act (behavior; default off, independent of version).
How to turn V4 on / roll back
• Dogfood privately (no effect on anyone else): open the app with ?skin=v4 appended to the URL, e.g. https://realifyai.app/?skin=v4. Force legacy with ?skin=legacy. The choice sticks for your session.
• Roll out to everyone: set Seller app UI build = v4, then scope = on. Use scope internal to keep the default legacy but allow per-session ?skin=v4 opt-in.
• Roll back instantly: set Seller app UI scope = off (everyone returns to legacy on their next navigation — no redeploy, no data loss). Or send anyone ?skin=legacy.
• Ask / Agents: enable the gate here only after the v4 build is rolled (they grey out otherwise). Agents stay in Observe — they don't act until the models + write-back are live.
